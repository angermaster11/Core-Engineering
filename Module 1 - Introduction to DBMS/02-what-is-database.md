# 2. What is a Database?

- **Database** = organized collection of logically related data — stored, accessed, managed, updated efficiently.
- Example: college database table `Students`:

| Student_ID | Name  | Course | CPI |
|------------|-------|--------|-----|
| 101        | Rahul | CSE    | 8.5 |
| 102        | Aman  | IT     | 7.9 |
| 103        | Priya | CSE    | 9.1 |

- A database ≠ one table. It holds many related tables: Students, Teachers, Courses, Departments, Attendance, Fees...
- Real world: Instagram login → account details, posts, followers, messages — all stored in databases.
