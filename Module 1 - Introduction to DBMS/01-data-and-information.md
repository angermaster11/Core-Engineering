# 1. What is Data?

- **Data** = raw facts, figures, observations — not yet processed or organized.
- Examples: Student name `Rahul`, Roll No `101`, Age `21`, CPI `8.5`, Salary `45000`.

## Types of Data
- **Structured** — fixed format → SQL tables
- **Semi-structured** — some structure → JSON, XML
- **Unstructured** — no fixed structure → images, videos, PDFs

## Data vs Information
- **Data** = raw facts without context → `80, 90, 70`
- **Information** = processed data with meaning → `Average marks = 80`

> 🎤 Interview: *Difference between data and information?* → Data is raw; information is processed data that gives insight.
