# 8. Real-World Applications of DBMS

- **Banking** — accounts, transactions, loans (e.g. HDFC)
- **E-commerce** — products, orders, payments, inventory (e.g. Amazon)
- **Healthcare** — patient records, appointments, billing
- **Education** — students, attendance, results, fees (university ERP)
- **Railway/Airline** — passengers, seats, tickets, payments (e.g. IRCTC)
- **Social media** — profiles, posts, followers, messages (e.g. Instagram)
