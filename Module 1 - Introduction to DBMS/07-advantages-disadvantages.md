# 7. Advantages & Disadvantages of DBMS

## ✅ Advantages
- Less redundancy, better consistency
- Data security & integrity
- Concurrent access + transaction management
- Backup & recovery built-in
- Data independence, easy retrieval

## ❌ Disadvantages
- High cost (setup + maintenance)
- Needs skilled DBAs
- Heavy on memory/CPU
- Overhead for tiny apps
- One failure → many apps affected
- Scaling needs planning

> 🎤 Interview: *Is DBMS always better?* → **No.** For simple static files, file system is fine. DBMS wins when you need structure, concurrency, security & transactions.
