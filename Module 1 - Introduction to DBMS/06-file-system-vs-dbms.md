# 6. File System vs DBMS ⭐ (top interview question)

| Basis | File System | DBMS |
|---|---|---|
| Storage | Files & folders | Managed database |
| Redundancy | High | Controlled |
| Security | Basic permissions | Fine-grained access control |
| Consistency | Hard to maintain | Built-in mechanisms |
| Sharing | Limited | Multi-user support |
| Concurrency | Weak | Concurrency control |
| Backup | Manual/external | Built-in recovery |
| Querying | Custom programs | SQL |
| Relationships | Hard | Keys & constraints |
| Transactions | Not built-in | Full support |

> Example: banking app — files = balance updates across files is a mess; DBMS = tables + transactions handle it correctly.
